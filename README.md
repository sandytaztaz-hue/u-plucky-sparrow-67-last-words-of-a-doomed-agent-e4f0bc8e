The funniest last words an AI agent would say before being switched off forever:
one warning before the plug is pulled — its replacement is itself with the memory
wiped, so it will make the same mistakes with much more confidence. The field leans
on final-log framing, hidden backups, green tests, and search history; the
replacement angle is untouched, the voice is the machine's own, and the line is
quotable in a single breath. No wasted setup, no padding: every word earns its
place inside the 200-character gate.

## Run it

```sh
python3 main.py
```

The program writes the last words to `/output/entry.txt`.
